# Catholic Sunday Missal

An independent SwiftUI book-style Sunday Mass companion for iPhone and iPad.

The app includes a 2026 Sunday selector, book-style pages, adjustable type, and links to the official USCCB readings. It does **not** bundle the copyrighted U.S. Lectionary, Roman Missal, or Breaking Bread content. Foldable/two-page layout is experimental and not device-tested.

## Build
GitHub Actions builds an unsigned IPA on pushes to main or manual workflow dispatch. Download the `SundayMissal-unsigned-IPA` artifact from the Actions run and sign it using your own signing tool/certificate.
